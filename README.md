# 聯盟造型圖鑑 & 進階戰績助手 (LOL Skin Library & Profile Tracker)

這是一款專為《英雄聯盟 (League of Legends)》玩家打造的開源小工具。它能直接與您電腦上運行中的英雄聯盟客戶端 (LCU) 連線，讀取您的帳號資料，為您提供最直觀的「造型收集進度」與「進階戰績分析」功能。

## ✨ 核心功能

### 1. 🎨 造型收集圖鑑
告別遊戲內建商城繁瑣的介面！為您一目了然地整理出您的造型庫存：
* **全英雄收集進度**：直觀顯示所有英雄的造型擁有數量與百分比，並提供「完全未擁有」、「部分擁有」、「已完成收集」等快速篩選。
* **精準稀有度標籤**：
  * `🔥 特價`：即時抓取商城特價資訊，並劃掉原價顯示折扣價。專屬「🔥 特價中」按鈕幫您一鍵尋寶！
  * `🔮 神話 / 轉蛋限定`：精準標示尊爵不凡、海克斯科技及轉蛋專屬的神話級造型。
  * `✨ 終極造型`：給予頂級造型專屬的金色標示。
  * `⏳ 典藏絕版`：標示出平常買不到的節慶或限定下架造型。
  * `🔒 特殊限定 / 轉蛋`：針對台服常見的無標籤轉蛋抽獎、通行證或賽季獎勵特別標示。
* **造型發布時間排序**：點開英雄後，造型會嚴格按照「最舊到最新」的發布時間排序，看清英雄演進史。
* **虛擬購物車**：看到喜歡的特價造型？先加入購物車，幫您試算總共需要花費多少 RP！

### 2. 📊 進階戰績總覽
比遊戲內建戰績提供更多、更直接的痛點資訊：
* **牌位與勝率卡片**：採用精美毛玻璃設計，動態顯示您的單雙排/彈性積分牌位圖示、勝點 (LP) 與總勝率。
* **單場進階表現分析**：
  * 結合 KDA 與傷害輸出自動評分。
  * 勝利方最高分會獲得金色的 **`MVP`** 徽章。
  * 戰敗方最高分會獲得灰色的 **`SVP`** 徽章。
  * 表現嚴重失常的玩家會被貼上醒目紅色的 **`戰犯`** 標籤，找戰犯不用自己算！
* **符文圖標透視**：詳細對戰面板中，不再是冷冰冰的數字，系統會自動轉換並顯示每位玩家的「主系基石與副系」符文圖標，讓您一眼看穿對手套路。

## 🚀 如何使用

1. 請先確保您已經開啟並登入了《英雄聯盟》遊戲大廳。
2. 點擊執行打包好的 `build/LOL-Skin-Library-App.exe` 檔案。
3. 程式開啟後，點擊「連接 League Client」，系統就會自動抓取您的資料並生成華麗的介面！

## 🛡️ 安全性與防毒軟體提示

本程式為 100% 開源且安全的專案，但由於是以獨立開發者的身分打包，未購買昂貴的商業數位憑證，在部分電腦上可能會遇到以下狀況：

* **Windows SmartScreen 藍色警告 (未知的應用程式)**：
  這是微軟的預設保護機制。當您第一次開啟時，請點擊左上角的 **「其他資訊」 (More info)**，接著點擊下方的 **「仍要執行」 (Run anyway)** 即可正常開啟。
* **防毒軟體誤判 (False Positives)**：
  由於本程式使用 `caxa` 技術，將 Node.js 執行環境與網頁原始碼打包成單一的 `.exe` 執行檔，這種「包裝式」架構非常容易觸發部分防毒軟體（例如 Avast、360 等）的啟發式掃描誤判。
  * **安全證明**：本程式已上傳至 VirusTotal 由 70 幾家防毒引擎掃描，主流防毒（如 Windows Defender、Kaspersky）皆顯示為安全。如果您有疑慮，隨時可以檢視本資料夾內的所有開源程式碼 (`server.js`, `public/*`)，程式絕對不會記錄或上傳您的任何個人密碼。

## 💻 開發與自行打包 (How to Build)

如果您想要自己修改介面或重新打包：
1. 確認您的電腦已安裝 [Node.js](https://nodejs.org/)。
2. 執行 `npm install` 安裝所有相依套件。
3. 執行 `npm run dev` 即可開啟本地開發伺服器進行測試。
4. **打包程式**：如果您修改了原始碼並想重新打包成 EXE 執行檔，請在終端機輸入：
   ```bash
   npm run build
   ```
   * 打包腳本 (`build.cjs`) 會自動壓縮檔案、載入 `icon.png` 應用程式圖示。
   * 最終完成的獨立執行檔會輸出到 `build/LOL-Skin-Library-App.exe`。
